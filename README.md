## 📝 Descripción del Proyecto

Este proyecto es una aplicación de consola desarrollada en **Python** bajo el paradigma de **programación estructurada**. Su objetivo principal es facilitar la administración básica de inventarios para pequeñas o medianas empresas mediante un menú interactivo y fácil de usar.

### 🚀 Funcionalidades Principales

* **Registrar nuevos productos:** Permite dar de alta artículos guardando código único, nombre, descripción, categoría, precio, stock inicial y stock mínimo.
* **Buscar productos:** Búsqueda rápida por código exacto o coincidencia parcial por nombre.
* **Eliminar productos:** Remueve artículos del inventario previa confirmación del usuario.
* **Control de entradas y salidas:** Incrementa o disminuye las existencias del stock con validaciones de inventario disponible.
* **Alertas de stock bajo:** Reporte de productos cuya cantidad sea menor o igual al stock mínimo configurado.
* **Visualización global:** Muestra el listado completo de los productos registrados.
